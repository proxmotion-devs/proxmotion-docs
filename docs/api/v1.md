# Billing API v1

All automated billing interactions communicate via the REST API prefixed at `/api/v1`.

## Authentication

Requests require a Bearer token generated for your billing system in the Proxmotion admin panel:

```http
Authorization: Bearer <api_token>
Accept: application/json
```

## Core Endpoints in v0.1

### Servers
- `GET /api/v1/servers`: List all managed instances
- `POST /api/v1/servers`: Provision a new instance
- `GET /api/v1/servers/{server}`: Detailed server info
- `POST /api/v1/servers/{server}/power`: Power operations (`start`, `stop`, `reboot`, `shutdown`)
- `POST /api/v1/servers/{server}/reinstall`: Trigger OS reinstallation

### SSH Keys
- `GET /api/v1/servers/{server}/ssh-keys`: List injected public keys
- `POST /api/v1/servers/{server}/ssh-keys`: Sync authorized keys

### Snapshots
- `GET /api/v1/servers/{server}/snapshots`: List snapshots & slots usage
- `POST /api/v1/servers/{server}/snapshots`: Create snapshot
- `POST /api/v1/servers/{server}/snapshots/{snapshot}/rollback`: Rollback to snapshot
- `DELETE /api/v1/servers/{server}/snapshots/{snapshot}`: Delete snapshot

### Backups
- `GET /api/v1/servers/{server}/backups`: List backup volumes & slots usage
- `POST /api/v1/servers/{server}/backups`: Trigger backup task
- `POST /api/v1/servers/{server}/backups/{backup}/restore`: Restore backup volume
- `DELETE /api/v1/servers/{server}/backups/{backup}`: Remove backup volume

### Usage
- `GET /api/v1/servers/{server}/usage`: Retrieve time-series usage statistics
